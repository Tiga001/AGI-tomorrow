# 玩法与规则（含剧透）

距离 AGI 只剩最后一步。距离发工资也只剩最后一天。

中文季度经营文字游戏：2021 Q1 至 2028 Q4，共32季。每季先从五个事件回应中选择一项，再从九项公司策略中选择三项，统一结算。

## 运行与构建

执行 `python3 build.py`，直接打开 `dist/index.html` 即可离线游玩；图片、音乐、音效和脚本全部内嵌。构建同时导出 `dist/endings.html`、`dist/endings.txt`、`dist/endings.json`，包含当前全部67种结局的完整标题与正文。

开发预览：`python3 -m http.server 8766 --directory dist`。

## 页面与交互

紫色背景、亮黄标题与荧光绿按钮。封面两侧为DeepSeek和Claude角色。开始创业后播放约4.6秒的开机过场，含风扇与键盘声；事件选项接受时播放原创机械落印确认音，约0.36秒进入策略阶段。策略选择只在执行后结算，结果延迟1.6秒揭晓。下一季度用1.6秒紫色过场衔接，左右角色浮现，中间显示新季度；末季显示结局。动画期间锁定输入，减少动态偏好下缩短或跳过过场。

顶部显示年份、季度、资金、研发、士气、风评、风险和科学家名单。属性变化实时预览；左侧友商关系只显示已结算数值：负数红色，0—59白色，60及以上绿色。没有往来时隐藏关系栏。事件标题居中，点击回应直接选择；策略页只保留九张卡与执行按钮。策略卡右上角显示净收支，属性和厂商关系位于底部。

音乐为Millennium Dawn主主题曲，循环音量25%；结算音30%。音乐及音效许可见 `assets/music` 和 `assets/sfx`。右上角统一开关控制声音，偏好独立保存。

## 经营规则

初始资金10亿元，内部货币单位为百万元；研发6、士气70、风评50、风险0。每季扣除固定开销和策略投入，计入经营回款、策略回款及事件收益；研发与风评会影响经营回款。科研类策略在研发80和160时各增加25%成本，硬件不随研究阶段涨价。研发无上限。

策略与硬件按季度解锁，基础里程碑每局一次，周期工作有冷却，人才项目需要相应科学家。出租算力需要硬件；开放权重需要尚未发布的模型；新模型会使较早的能力验证失效。技术路线包含Tokenizer、Transformer、LoRA、MoE、Computer Use、MCP、Harness、自进化及有限的RSI与对齐实验，预研本身不等于AGI。

可招募10位科学家：Tibo、姚顺雨、苏剑林、罗福莉、杨植麟、唐杰、Ilya、Karpathy、崔添翼、李飞飞。招募出现概率随风评增长，已招募者不重复。Tibo从2025 Q2起在普通招募之外另有18%的额外邀请机会，不替换原普通人才抽样；开放人才计划的概率不变。Tibo的专属策略为“为用户 Reset”和“发放重置卡”，均在招募后的季度开放，属于用户福利，不增加研发。“发放重置卡”固定投入2,600万元，不随研发阶段涨价；士气、风评、风险、好感与冷却规则保持不变。按本游戏设定，Karpathy从2021 Q2起属于Anthropic／Claude合作方向；不代表现实履历。

## 公司与剧情

10家核心公司：OpenAI、Anthropic／Claude、DeepSeek、Kimi、Google／Gemini、千问、华为、小米、xAI、英伟达。关系范围−100至100；采购、招募、公司策略与事件选择都可改变关系。Google／DeepMind从2021年以已有研究参与，2023 Q4前使用Google名称与图标，之后显示Gemini，好感连续累计。豆包、文心、混元、智谱／GLM仅保留历史事件和人物背景，不再占用可选合作回应。

2021—2026事件先抽3家不同的核心公司，再加自主与公共回应，共5项。每轮至少2家非硬件公司，华为与英伟达最多出现1家；按公司真正进入候选池的次数与已出场次数平衡机会，近两季出现过的公司降低权重，好感只轻微影响抽取。所有厂商回应都有Logo和非零主厂商关系变化；采购可同时增加供应商关系并降低竞争方关系。合法候选存档后刷新不会重新抽取；已结算回应ID保留；未结算候选调整时保留玩家已选项。

2025 Q3固定发生“Claude 还在，账号没了”，背景为地区及企业控制权限制；2026 Q2固定发生“买的是 Claude，端上来的是豆包”，中转供应商和查证过程为虚构。2026 Q3固定发生Boris邀请Tibo的事件，三张厂商回应中必有直接招募Tibo的选项；招募费与收益按事件卡一次结算，已有Tibo则改为留任福利。事件招募不会与同季策略招募或人才计划重复，专属项目从下一季度开始可选。更新只调整存档中尚未看到的后续固定事件，保留已结算记录和当前已确认回应。

2027 Q1固定选择下一阶段方向：第一项单干，其后为已结算好感最高的四家核心公司。同分按此前合作次数和公司ID排序，零分或负分也补足四家。正文保留对应四封合作来信，按钮只写单干或与某公司合作冲击AGI，不显示结局名称。

2027—2028沿所选公司或自主路线展开。资金低于1.8亿、士气低于35、风险达到45或主伙伴好感低于15，触发经营承压场景；研发领先且团队与关系稳定时可触发领先场景。2028 Q1若另一公司好感至少35且领先当前伙伴至少12，会出现明确转向机会；事件也允许离开伙伴独立经营。开放、控制等方向次数随选择累计，更换伙伴不清零。

## 当前67种结局

只保留11条现行路线的64个结局及3个通用失败结局。

AGI需要研发≥450、风评≥55、士气≥40、至少2位科学家，拥有模型并在2028年对最新版本完成有效验证；训练新模型后需重测，也可同季训练与验证。存活至2028 Q4后按以下顺序判断：

1. 达成AGI，但当前伙伴好感不足60，进入合作分离；独立和英伟达没有此分支。
2. 达成AGI，控制至少3次且多于开放，进入控制方向结局；否则开放至少3次，进入开放方向结局；其余进入常规突破。
3. 未达成AGI，若研发低于150、士气低于25、风评低于25、风险达到55或伙伴好感低于15，进入路线崩裂；独立不检查伙伴好感。其余进入未兑现AGI但公司继续经营的结局。

任何季度资金归零会破产，士气归零会散伙；第6季起风险达到70会清盘，优先于末季正常判定。在英伟达路线中，这些提前失败统一触发《最后一份交付单》。完整文案见构建生成的结局审阅页。

## 存档

当前存档键为 `agi-tomorrow-game`。载入时删除已停用的旧游戏存档键，不迁移旧进度，声音偏好保留。当前存档记录完成的季度、抽牌、阶段、已选项和结局收藏；刷新继续当前局。历史版本规则、旧结局、退出公司的世界线和兼容判断均已移除。

## 文件

- `index.html` / `style.css`：界面结构与样式。
- `story.js` / `partners.js`：历史事件、当前事件回应、公司资料与通用失败文案。
- `strategies.js`：当前策略、招募、技术解锁、成本与效果。
- `worldlines.js` / `worldline-engine.js`：11条路线的剧情、合作入口、分支和64个结局。
- `game.js`：当前单一规则的回合、结算、存档与页面控制。
- `music.js` / `sound.js`：音乐与音效。
- `build.py` / `export_endings.py`：离线构建及完整结局导出。
- `research/`：事实核验及来源记录，不在游戏内显示。

2021—2026的公开行业事件提供背景，玩家公司、招募、合同、数值与对话属于游戏虚构；2027—2028属于未来架空故事。品牌不代表参与或认可。素材许可和来源在assets下保留。
